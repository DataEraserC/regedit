# linux-regedit

> Linux 版 regedit —— 用 **C + GTK3** 编写，在视觉与交互上模仿 Windows 注册表编辑器（`regedit.exe`）的**系统配置文件浏览器**。

本项目把 Windows `regedit` 的经典交互「左侧注册表树 + 右侧键值列表」映射到 Linux 世界：

| Windows 概念 | 本项目的映射 |
| --- | --- |
| `HKEY_LOCAL_MACHINE`（系统级配置） | `/etc` |
| `HKEY_CURRENT_USER`（用户级配置） | `~/.config` |
| 注册表树（键/子键） | 文件系统目录树 |
| 注册表值（名称 / 类型 / 数据） | 解析后的每一条配置项 |
| 值类型（`REG_DWORD` / `REG_SZ` 等） | 数字 / 字符串 / 布尔值 |
| — | 配置文件的注释以**备注**列展示 |

---

## ✨ 特性

- 🗂️ **双根键文件树**：以 `/etc` 与 `~/.config` 为根，左侧以树形展示配置文件目录结构。
- 🔍 **配置解析为可视化选项**：受支持的配置文件被解析成**逐行配置项**，而不是一坨纯文本。
- 🧮 **智能类型识别**：程序自动区分配置值的类型——
  - 数字（整数 / 浮点，类比 `REG_DWORD` / `REG_QWORD`）
  - 字符串（类比 `REG_SZ` / `REG_EXPAND_SZ`）
  - 布尔值（`true/false`、`yes/no`、`0/1`，类比 `REG_DWORD` 的 0/1）
- 💬 **备注列**：配置文件中对应的注释（`#`、`;`、`//` 等）作为备注随配置项一同显示。
- 📝 **回退为文本编辑器**：暂不支持的格式直接以纯文本视图打开，保证任何配置文件都可浏览。
- 🎨 **regedit 风格界面**：经典三栏（名称 / 类型 / 数据）+ 备注列，左侧树可展开收起，配色与布局贴近 Windows regedit。

## 📦 支持的配置文件格式（v0.1）

> 均为「一行一条配置」的键值对风格，天然符合「每一行配置变成一个可视化选项」的设计；其余格式会以文本编辑器兜底展示。

| 格式 | 语法要点 | 示例位置 |
| --- | --- | --- |
| **INI**（分节键值） | `[节]` + `key = value`；注释 `;` / `#` | `~/.config` 下大量应用配置 |
| **扁平 KeyValue** | `key=value` / `key value`，无分节 | `/etc/environment` 等 |
| **systemd unit** | `[Unit]/[Service]` 等节 + `Key=Value` | `/etc/systemd/system/` |

后续版本将扩展：`JSON`、`TOML` 等结构化格式（见 [Roadmap](#-roadmap)）。

## 🧩 数据类型

| 配置文件中的写法 | 识别类型 | regedit 类比 |
| --- | --- | --- |
| `123`、`3.14`、`0x1F` | 数字 | `REG_DWORD` / `REG_QWORD` |
| `"..."` 或普通文本 | 字符串 | `REG_SZ` |
| `true/false`、`yes/no`、`on/off`、`1/0` | 布尔值 | `REG_DWORD (0/1)` |
| `# ...` / `; ...` / `// ...` | 备注（注释） | 显示在备注列 |

类型识别规则基于内容启发式判断，并支持在查看时手动切换显示形式。

## 🛠️ 构建与运行

### 依赖

- **GTK3**（`libgtk-3-dev`）
- **GLib / GIO**（通常随 GTK3 一并安装）
- **Meson** ≥ 0.60 与 **Ninja**

Debian / Ubuntu：

```bash
sudo apt install build-essential libgtk-3-dev meson ninja-build
```

### 编译

```bash
meson setup builddir
meson compile -C builddir
```

### 运行

```bash
./builddir/linux-regedit
```

> ⚠️ 提示：`/etc` 下部分文件需要 root 权限才能读取，此时可用 `sudo` 运行以获得完整目录树；程序也会在界面中标注无法读取的文件。
